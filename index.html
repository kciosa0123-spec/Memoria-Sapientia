    端末間の同期（GitHub Gist）

    非公開のGistに学習記録を保存し、PCとスマホで同じ記録を使えるようにします。各端末で一度だけトークンを貼ってください（2台目以降は既存のGistを自動で見つけます）。

    トークンの作り方
    1. GitHub → 右上アイコン → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
    2. Note に「Memoria Sapientia」など、Expiration は任意（期限が来たら作り直して貼り直します）
    3. スコープは gist だけにチェック → Generate token
    4. 表示された ghp_… をコピーして下に貼り付け

    トークンはこの端末のブラウザにだけ保存され、バックアップファイルには含まれません。gist権限のみなので、漏れてもリポジトリには触れません。

    バックアップ

    学習記録と追加した問題はこのブラウザ内に保存されています（同期をオンにしている場合はGistにも保存されます）。念のため、ときどき書き出しておくと安心です。
